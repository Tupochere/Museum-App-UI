# mtengatenga_ar

Flutter museum app for artifact discovery, QR-based artifact lookup, and offline-first data access.

## Quick Start

1. Create `.env` in `mtengatenga_ar/` with:
   - `SUPABASE_URL`
   - `SUPABASE_ANON_KEY`
2. Install dependencies:
   ```bash
   flutter pub get
   ```
3. Run analysis:
   ```bash
   dart analyze
   ```
4. Run app:
   ```bash
   flutter run
   ```
